 C# - Métodos e Funções

Exercícios de C# focados em métodos e funções.

 Exercícios
- ContarVogais — recebe uma string e devolve o número de vogais
- Inverter — recebe uma string e devolve ao contrário
- Repetir — recebe uma string e um número e devolve a string repetida
- Palindromo — recebe uma string e devolve true ou false
- ContarPalavras — recebe uma string e devolve o número de palavras
